## Purpose

This capsule integrates a persistent PACA skill into the existing
SIGIL4CPython polyglot localization stack. The skill is bound to PACAIoGames,
SIGIL4Godot, Pydantika annotated types, Diskotika typed composition,
PACA Antorcha resource plans, Quazris localization, STRIKK validation, a Lean 4
boundary proof, and an Arakne source-bound semantic-fusion plan.

The compiler emits three canonical metadata artifacts:

```text
SIGIL_AST_V1
  → SIGIL_SYNTACTICAL_KERNEL_V1
  → SIGIL_SEMANTICAL_KERNEL_V1
```

These are reviewable typed plans. They are not a claim that a Godot process,
PyTorch model, CPython interpreter change, deployment, or physical Git branch
merge has executed.

```text

```

A validator can be:

```text

HOLD

```

`DECLARED` means that the structural contract and source reference exist but a
hosted validator still has to execute. The dependency-free compiler may emit
`ADMIT_PLAN_ONLY` while hosted validation remains required. A failed exact
boundary produces `REJECT`.

## Admission law

```text
ADMIT_PLAN_ONLY
  iff
    all structural checks pass
    and no exact validator is failed or held
    and runtime/deployment/Git merge remain false
```

```text
HOLD_WITH_OBSTRUCTION
  if
    a bounded type, composition, localization, or witness obstruction remains
```

```text
REJECT
  if
    identity transport
    or plural collapse
    or runtime execution
    or deployment
    or physical Git merge
    or branch identity collapse
    or unbounded PACA Antorcha authority
    or failed exact validator
```
