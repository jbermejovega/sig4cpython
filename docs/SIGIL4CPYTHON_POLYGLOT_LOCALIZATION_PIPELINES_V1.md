## Core Law

SIGIL localization is a plural typed graphical-calculus algorithm.  It uses
aperiodic cellular tilings to localize annotated types without collapsing
different surfaces into one carrier.

```text
SIGIL_GRAPHICAL_CALCULUS
  -> aperiodic_cellular_tiles
  -> pydantika_annotated_relation_types
  -> localized_polyglot_bindings
  -> universal_abstract_pipeline
```

The kernel is metadata only.  It does not import PyTorch, Macaulay2, OpenMPI,
Godot, sigil4py, or any hardware-facing runtime.

## Plural Relation Rule

The localization rule preserves the linter canon from the attached
STRIKK plural typed linter note:

```text
all_types_are_relations
all_relations_are_types
no_single_type_collapse
trace_preserved
```

Lexical normalization is allowed only with preserved input trace.  For example,
`endofukntor` canonicalizes to `endofunctor`, and `quzris` canonicalizes to
`quazris`; neither input spelling is silently erased.

is the algebraic-geometric semantic LLM layer.  Quantum Quimbo is explicitly
not a Linux kernel.

## OpenMPI Compliance

OpenMPI compliance is STRIKK typed and guarded:

```text
single_rank_fallback = true
mpi4py_optional = true
explicit_mpiexec_required = true
rank_witness_required_for_multi_rank = true
scheduler_mutation = false
performance_claim_without_benchmark = false
```

No MPI import or rank execution happens in the localization kernel.  A
multi-rank witness belongs to the explicit OpenMPI compatibility workflow.
